## Tic-Tac-Toe
My first python game not for school.

## About
This game (At least for now) is just a boring tic tac toe game playable in a terminal. The purpose of this game is to make a game anyone can play in a browser python IDE. The reason for that is because I'm making this for people who are stuck in school with just a Chromebook. There are no terminals, but there are amazing sites like https://www.onlineide.pro/playground/python to be able to run python code on Chromebooks (or any divice with a keyboard and browser!).

## Current state
Right now, it's not even fully done, or started in some sense. I have the framework and needed functions, lists, and variables, just none of the logic. But the plan for this game is to be almost chaotic with a bunch of different abilities! But for now, I have to try and just make the basic game itself.

## How to Run
WARNING, CURRENT VERSION IS NOT EVEN REMOTELY PLAYABLE!!!

# All divices
If you want to run this project specifically and in a browser, go to: https://www.onlineide.pro/share/5f102a7d-4760-4de6-8fcb-9f082888e4ff

# Windows/MacOS/Linux
if you want to run it natively (like any python project), first make sure you have downloaded python, then go to your Terminal/CMD/Konsole (it's all the same thing, just different names), type `cd "exact/location/of/python/files/"`
then type `python main.py`
